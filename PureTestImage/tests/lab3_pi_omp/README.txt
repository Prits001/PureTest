================================================================================
Практическое задание: Вычисление числа Пи (ряд Лейбница) — Sequential vs OpenMP
Формула: pi = 4 * sum_{n=0}^{N-1} ((-1)^n / (2*n + 1))
================================================================================

Данный лабораторный тест демонстрирует сравнение двух вариантов реализации O(N):
  * base.cpp — последовательное вычисление в 1 поток (O(N))
      Знак переключается операцией (sign = -sign), знаменатель
      накапливается сложением (denom += 2.0).
  * opt.cpp  — параллельное многопоточное вычисление через OpenMP
      Используется директива: #pragma omp parallel for reduction(+:s).
  * inputs.txt — сетка значений N (число членов ряда).
  * build.flags — флаг сборки -fopenmp.
  * max_base_n — повышенный лимит N для base.cpp (поскольку base тоже O(N)).

Запуск в меню PureTest:
  [lab] -> выбрать 'lab3_pi_omp'
  или ввести в консоли: lab lab3_pi_omp

Результаты:
  * accuracy_table.tsv — оценка погрешности относительно pi = 3.1415926535...
  * timing_table.tsv   — таблица времени и выигрыша (%) по уровням O0, O1, O2
  * threads_table.tsv  — исследование масштабируемости (время, ускорение S, эффективность E)
  * machine_specs.tsv  — паспорт аппаратной архитектуры ПК
================================================================================
